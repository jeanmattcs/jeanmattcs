# Jean

Backend Developer focused on reliability, consistency, and predictable system behavior.

I enjoy designing systems that remain correct under failure, recovery, and high-load scenarios. My main interest is ensuring it behaves deterministically when things go wrong.

I tend to think about persistence, recovery, auditability, and execution flow early in the design process, aiming to transform complex business rules into maintainable and reliable systems.

## What I work on

### Reliability & Consistency

Designing mechanisms that protect data integrity and ensure predictable system behavior across failures, restarts, and unexpected conditions.

### Runtime Design

Building execution flows that prioritize determinism, fault tolerance, and operational stability.

### Software Architecture

Applying Domain-Driven Design, Clean Architecture, and modular design principles to create systems that can evolve without accumulating unnecessary complexity.

### Performance & Scalability

Optimizing resource usage, reducing bottlenecks, and maintaining stable performance under load.
